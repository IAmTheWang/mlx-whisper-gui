# web/

Frontend: vanilla TypeScript + Vite, no framework (no React/Vue/etc). Single-page, single-screen app — there is no client-side router.

- `index.html` — the single HTML shell, mounts `#app`.
- `src/` — all application code; see its own `CLAUDE.md`.
- `vite.config.ts` — **`build.outDir` points directly at `../internal/server/dist`** with `emptyOutDir: true`. This is load-bearing: `internal/server/embed.go` does `//go:embed dist`, so `make build` needs no separate copy step between the frontend build and the Go binary. Don't change this path without updating `embed.go` too.
- Dev server proxies `/api` to `http://localhost:8787` (`server.proxy` in `vite.config.ts`) — run `make dev-api` alongside `npm run dev` for a working dev loop.
- `tsconfig.json` — `strict: true`, `noUnusedLocals`/`noUnusedParameters` on; keep new code passing these, there is no separate lint step.
- `package.json` — only two scripts, `dev` and `build`; no test runner configured for the frontend.
- `node_modules/`, generated by `npm install` — gitignored, no `CLAUDE.md`.

## Build

```bash
npm install
npm run dev     # Vite dev server (needs `make dev-api` running separately for /api)
npm run build   # outputs straight into internal/server/dist
```
